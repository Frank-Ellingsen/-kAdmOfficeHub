# Office Hub - Det Norske Brenneri AS (Org 996 928 977)

System for Økonomi, Regnskap, Særlovgivning, Likviditet og Logistikkoptimering.

## 🚀 Funksjonalitet
- **Master Web UI (`index.html`)**: Publisert på GitHub Pages med interaktive faner, datalinje/proveniens, tooltips og sanntidsberegninger.
- **Lineær Programmering (LP) Logistikk**: Minimerer transport- og ruteutgifter fra Grimstad til Vinmonopolet, grossister (Asko/SG) og Horeca.
- **3-Statement FP&A & Early Warning Radar**: Overvåking av lagertid (DIO), kredittid (DSO), prosjektrisiko (EAC) og skattetrekk (100% dekning på konto 1925).
- **Varelager & Fatlager-splitt**: Skiller råvarer, fatlager under modning (WIP) og fortollet ferdigvarelager.
- **Vinmonopolet Anbudskalkulator**: Beregning av særavgifter (alkoholavgift kr 942,50/L ren alk.), MVA, Pol-avanse og DB1/DB2.
- **Antigravity 7 Multi-Agent Network**: Autonom agentarkitektur for ruting, MVA-regler, DuckDB SQL, Altinn og årsoppgjør.
